Sentinel Public Dataset

Sentinel publishes cryptographically verified moderation events as a public dataset. Events are periodically exported from the verification API and stored as append-only snapshots.

Each snapshot is deterministic and contains only verified events.

Dataset snapshots are append-only and never overwritten.

Dataset Manifest

https://storage.googleapis.com/dce-ma-snapshots/index.json JSON

The dataset manifest is primarily intended for developers, researchers, and automated replication tools. It lists all available snapshots and provides metadata about the dataset. Replication tools should fetch this manifest to discover the latest dataset version, then read the latest.url field and download the latest snapshot from that URL.

Dataset Replication

For automated dataset replication or research workflows, follow these steps:

1
Fetch the dataset manifest
GET https://storage.googleapis.com/dce-ma-snapshots/index.json
2
Read the "latest.url" field
Parse the JSON response and extract the latest.url value — this points to the most recent snapshot file.
3
Download the snapshot
Stream or download the file at latest.url. Snapshots are append-only and never overwritten, so existing downloads remain valid.
4
Parse the JSONL file
Each line in the downloaded file represents a single verified SentinelEvent. Split on newlines and parse each line as independent JSON.

Replication tools should always fetch the manifest first rather than hardcoding snapshot URLs.
